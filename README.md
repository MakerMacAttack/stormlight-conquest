# Dev Stuff

## Branch conventions

### To make a new branch:

`git switch -c [new branch name]`

### Naming Conventions:

Prefence with the type of branch. Feature, Bugfix, Hotfix, Release, Documentation. Then a backslash, then the name of the branch in kebab case.

Format:

`type/here-is-the-name`

Examples:

`bugfix/stop-shinovar-from-spinning`

`feature/add-oathgates`

`release/1.1.2`
